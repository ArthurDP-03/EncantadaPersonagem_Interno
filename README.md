# EncantadaPersonagem_Interno
Durante um projeto acadêmico, eu e meus colegas João Victor Saboya, Alexandre Tucci e Matheus Bortolli tivemos a oportunidade de desenvolver um software de gestão interna para a Encantada Personagens, uma empresa referência no segmento de entretenimento infantil no Paraná, com atuação em Curitiba e região.

O desafio era claro: substituir processos realizados em cadernos de agenda e planilhas do Excel por uma plataforma centralizada, capaz de oferecer mais organização, transparência e eficiência operacional.

O sistema desenvolvido contempla funcionalidades que vão desde o gerenciamento do estoque de personagens e fantasias até a gestão completa dos eventos, permitindo maior controle das operações e contribuindo para a modernização dos processos da empresa.

Esse projeto foi uma excelente oportunidade para aplicar conceitos de engenharia de software, desenvolvimento full stack, modelagem de banco de dados e trabalho em equipe na resolução de um problema real.
